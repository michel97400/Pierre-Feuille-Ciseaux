
# Pierre-Feuille-Ciseaux

## Description
Ce projet est un jeu en ligne de commande où vous pouvez jouer à Pierre-Feuille-Ciseaux contre l'ordinateur.

## Installation
1. Clonez ce dépôt :
	```bash
	git clone https://github.com/michel97400/Pierre-Feuille-Ciseaux.git
	```
2. Placez-vous dans le dossier du projet :
	```bash
	cd Pierre-Feuille-Ciseaux
	```
3. (Optionnel) Créez un environnement virtuel :
	```bash
	python -m venv venv
	venv\Scripts\activate
	```

## Utilisation
Lancez le jeu avec la commande suivante :
```bash
python main.py
```
